# compact 实验结果

日期：2026-10-29。方案：[实验方案 A](../design/实验方案-compact与多槽.md)。结论：**sparse bundle 卷内删除数据后，正常卸载不会自动释放 band；`hdiutil compact` 能回收，耗时不到 0.5 秒，compact 后 103,109 项内容完全一致，两轮运行验证各 23/23 通过。** 中断测试 A10 未做（需另行授权）。

## 对象与方法

- 工作映像：`artifacts/experiments/compact-20261029/work.sparsebundle`，由 `miniconda.sparsebundle` APFS 克隆而来，克隆后逐 band 名与 `Info.plist` 比对一致。原映像未挂载、未修改。
- 固定路径 `~/.local/dev/miniconda/current` 挂载；全程只挂这一个副本（卷 UUID `91FF58B2-…` 与来源相同）。
- 占用口径：bundle 内所有文件的 `st_blocks × 512`（克隆共享的块也计入）；宿主可用空间另记于各测量 JSON 的 `hostFreeBytes`。band 大小 8 MiB。
- 验证用新的参数化脚本 [`verify_volume.py`](../../artifacts/experiment-support/compact-multislot-20261029/verify_volume.py)，与上次相同的 23 项；先做负向对照（原安装读取被拒），禁网，禁读 Homebrew 与 `/usr/local`。

## 结果

| 步骤 | band | 已分配字节 | 说明 |
|---|---:|---:|---|
| A1 基线（克隆前测源映像） | 304 | 2,535,456,768 | |
| A2 不做改动直接 compact | 286 | 2,370,269,184 | 回收 157.5 MB，0.41 s。说明昨天实验中删除的数据（如 python3.10 重建）一直没有释放 |
| A4 卷内写入 2 GiB 随机数据并卸载 | 542 | 4,518,801,408 | 恰好 +2 GiB |
| A5 删除该文件、`sync`、卸载，**不 compact** | 542 | 4,518,801,408 | **释放 0 字节** |
| A6 compact | 286 | 2,371,088,384 | 回收 2.0 GB，0.46 s |
| A9 两轮验证（建/删临时环境）后再 compact | 286 | 2,371,088,384 | 回收 0 字节 |

- A7：compact 前后内容清单（排除 `tmp/` 和 `.fseventsd`）**103,109 项**的类型、模式、大小、SHA-256、链接目标全部一致。
- A7 compact 后运行验证 23/23；A8 再次卸载重挂后 23/23。
- A9 原计划清理可重建缓存（`cache/pip`、`cache/xdg`），但实际只有 4 KB 的持久化标记文件，没有可清理的数据；改为测量正常使用后 compact 的回收量，结果为 0。
- `hdiutil` 输出中的"out of 5.6 GB possible"是卷的虚拟剩余容量，不是可回收量。

## 对设计的结论

按方案判定规则，属于"A5 未释放，A6 回收显著，A7/A8 全通过"：

1. **compact 有价值**：卸载不会自动回收，卷内删除过大量数据（重建环境、清缓存、升级后删除旧包）后，只有 compact 能把空间还给宿主。
2. 将 compact 作为 `mutate` 级操作开放，流程为：卸载 → 克隆为临时副本 → compact → 内容清单比对 + 运行验证 → 原子替换 → 原映像标 `retired`。
3. 在 A10 中断测试之前，"先在临时副本上 compact"保持为硬性要求，不允许原地 compact。compact 本身极快，副本流程的主要成本是验证。
4. UI 可在 compact 前显示估计可回收量：卸载状态下 band 总量与卷内已用空间之差只是上限，实际回收以整块空闲的 band 为单位。

## 未覆盖与局限

- A10 中断测试未做。
- 本次回收的 2 GiB 是一个连续的大文件，占满整块 band；大量小文件分散删除时，部分空闲的 band 无法回收，实际收益可能低得多。未测。
- 只在内置盘、未加密映像上测量；外置 SSD、加密映像、更大卷未测。
- 耗时为热缓存下的单次测量，不是性能基准。

## 过程记录

- A1 的第一次测量因 zsh 不拆分 `$P` 变量而没有执行，compact 已先跑。由于克隆与源映像逐 band 一致，改用源映像的只读测量作为 A1 基线，文件名标明了这一点。
- 原安装（103,075 项）与 `~/.zshrc`、`~/.condarc`、`~/.conda/environments.txt`、`~/.zprofile` 摘要在实验前后不变；实验开始前的原安装清单也与昨天的基线一致。
